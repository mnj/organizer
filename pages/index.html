Organizer

File-triaging desktop app — one image at a time, shortcuts, duplicate tracking. Single-file AppImage, no system gtk/gstreamer install needed.

Download Organizer-x86_64.AppImage 
chmod +x Organizer-x86_64.AppImage
./Organizer-x86_64.AppImage /tmp/src

No GPU? Run with GSK_RENDERER=cairo. Delta updates via AppImage.zsync (AppImageUpdate). All versions: releases. This page lives at mnj.github.io/organizer.
